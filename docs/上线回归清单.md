# 上线回归清单

**用途**：域名打通后，按这份清单从零跑一遍，确认「同步、好友、提醒、隐私」四条链路可用。
**原则**：每一条都写清「怎么点、该看到什么、没看到时查哪里」，不靠记忆。

---

## 零、前置：域名打通的五步

备案接入通过后，按顺序执行，每步都有验证点。

| # | 动作 | 验证 |
|---|---|---|
| 1 | `ssh root@8.153.164.6` → `certbot --nginx -d api.laleme.ariel.today` | 输出 `Congratulations`，`/etc/letsencrypt/live/` 下有证书 |
| 2 | `curl -I https://api.laleme.ariel.today/api/health` | `HTTP/2 200`，返回 `{"ok":true,"driver":"mysql"}` |
| 3 | 小程序后台 → 开发管理 → 服务器域名 → request 合法域名 | 填入 `https://api.laleme.ariel.today`（每月只能改 5 次，别填错） |
| 4 | 客户端 `baseUrl` 指向 `https://api.laleme.ariel.today`，`mode` 保持 `http`（直连含 https） | 重新编译 |
| 5 | `TOKEN=... bash laleme-server/deploy/smoke.sh https://api.laleme.ariel.today` | `10 通过，0 失败` |

> 第 2 步若仍返回 403 `Non-compliance ICP Filing`，说明备案尚未生效，回到等待。

## 二、记录链路（含订阅弹窗）

| # | 步骤 | 预期 |

| 2.1 | 点首页大按钮 | 底部抽屉升起，计时开始走 |

**失败排查**：

- 弹窗没出现 → 微信要求 `requestSubscribeMessage` 在点击的同步栈里调用，检查 `record-form.js` 的 `submit()` 里 `askSync('daily')` 是否在第一个异步操作之前
- 弹窗出现但额度没涨 → 查服务端 `push_quota` 表；日志 `[push:dry-run]` 说明 `PUSH_DRY_RUN=1` 未关

```sql
-- 额度核对
SELECT openid, template_id, count FROM push_quota;
-- 发送记录
SELECT type, day, FROM_UNIXTIME(sent_at/1000) FROM push_logs ORDER BY sent_at DESC LIMIT 5;
```

## 八、每日提醒

| # | 步骤 | 预期 |
|---|---|---|
| 8.1 | 当天不记录，额度 ≥ 1，手动触发 | 收到「每日习惯记录提醒」 |
| 8.2 | 同一天再触发 | 不重复发送 |
| 8.3 | 当天已记录再触发 | 跳过（`skippedDone`） |
| 8.4 | 额度 = 0 时触发 | 跳过（`skippedQuota`），不发 |

```bash
S=$(grep '^CRON_SECRET=' /etc/laleme-server.env | cut -d= -f2-)
curl -X POST http://127.0.0.1:3000/api/cron/daily -H "x-cron-secret: $S"
# 返回 {"users":N,"sent":X,"skippedQuota":Y,"skippedDone":Z}
```

手动补额度（仅测试用）：

```bash
curl -X POST https://api.laleme.ariel.today/api/push/quota \
  -H "Authorization: Bearer <令牌>" -H 'content-type: application/json' \
  -d '{"kind":"daily","count":1}'
```

## 附：已知会在回归中出现的现象

| 现象 | 说明 | 处理 |
|---|---|---|
| 订阅框允许后额度仍是 0 | 上报失败（网络/令牌） | 查 `push_quota`；确认 `baseUrl` 可达 |
| 好友卡片分享出去对方打不开 | 邀请码一次性、48 小时有效 | 重新邀请 |
| 记录删了但另一台还在 | 墓碑未上传成功 | 检查 `/api/sync/push` 返回的 `rejected` |
| 提醒没在 20:00 发 | systemd timer 时区或服务未起 | `systemctl list-timers laleme-cron.timer` |
| 首页计数与段位页不一致 | 两处都会结算段位，需拉一次同步 | 下拉或重进首页触发 `syncInBackground` |
