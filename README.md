## 为什么做它

现代人对体重、步数、睡眠都有仪表盘，却对身体最诚实的信号视而不见。

排便形态是消化系统最直接、最廉价的观测窗口——国际医学界为此建立了标准（**布里斯托大便分类法，Bristol Stool Scale**），消化科医生问诊时几乎必问。但没有人会随身带一本记录手册。

**「拉了么」想做的，是把这段被羞耻感遮蔽的健康数据，交还给每个人自己。**

我们不诊断、不上报、不制造焦虑。我们只提供一面镜子：记录、呈现、提醒你何时应该认真对待，或去咨询消化科医生。

## 三条产品原则

**1. 隐私是默认值，不是功能。**
所有数据存储于本机（`wx.setStorageSync`），无账号、无云端、无埋点、无 SDK。清空即消失，断网可完整使用。我们甚至没有服务器可以泄露。

**2. 记录成本必须趋近于零。**
一次记录 ≈ 10 秒：计时或手动输入时长，点选布里斯托类型，选一个满意度。多一步都会让人放弃坚持，而坚持本身就是这个产品最大的价值。

**3. 用设计消解尴尬。**
严肃的医学分类法被翻译成人人能懂的语言，配上不太正经的文案和庆祝动画。健康习惯的养成，需要一点幽默感的许可。

## 功能一览

- **快速记录**：计时器 / 手动时长 / 日期时间补记，单次上限 12 小时（超过该去挂号了）
- **布里斯托 7 型分类**：附「不确定」选项，每型配医学描述与通俗提示
- **健康统计**：周/月视图，频次、时长分布、满意度趋势
- **打卡日历**：每月打卡一目了然，💩 标记每一次坚持
- **连续打卡与成就系统**：13 枚成就徽章，记录即奖励
- **庆祝动画**：彩带 + 烟花 + 星星人，献给每一次如释重负
- **挑战分享**：canvas 生成专属海报，把连续记录发给好友发起挑战（纯分享机制，不读取任何好友数据）
- **数据可携带**：一键导出 CSV 到剪贴板，你的数据随时可以带走
- **隐私授权**：符合微信平台规范的隐私告知与同意流程，拒绝即退出，绝不静默收集

## 技术实现

```
laleme-miniprogram/       微信小程序（原生框架，零依赖）
├── app.js                全局配置 + onNeedPrivacyAuthorization 接入
├── pages/
│   ├── index/            首页：状态卡 / 日历 / 庆祝动画 / 隐私弹窗 / 分享海报（canvas 2d）
│   ├── record/           记录页：计时、布里斯托选择、编辑与删除
│   ├── stats/            统计页：周月指标、分布图、成就墙
│   ├── privacy/          隐私保护指引全文
│   └── me/               我的：数据概览、导出、清空
└── utils/
    ├── constants.js      布里斯托分类、成就规则、隐私文本
    └── record-store.js   本地存储层（list/create/update/remove，含字段校验）
```

- **原生小程序框架**，无第三方依赖，代码包 45KB
- **canvas 2d** 动态绘制分享海报（600×960，dpr 适配）
- **隐私合规三层设计**：首启弹窗（`open-type="agreePrivacyAuthorization"`）→ 指引全文页 → 常驻入口，配合 `wx.onNeedPrivacyAuthorization` 动态应答
- Web 版原型（`拉了么/index.html`）与产品设计文档（`拉了么-产品设计文档.md`）同仓库维护

## 本地运行

1. 克隆本仓库
2. 微信开发者工具导入 `laleme-miniprogram/`（基础库 ≥ 2.30.0）
3. 填入自己的 AppID，或使用测试号
